basics of PL : 
    1. where to store data
        variable : used to store data
        age = 30 ----> here age is variable and 30 is data

    2. what type of data
        numeric - int, float, complex 
        characters - str (string)
        yes/no - boolean
        collection - list, tuple, set, frozenset, dict (dictionary)
    3. operation on data 
        operators : symbols, used to perform operation on data
        arthmatic : +,-,*,/,%
        assigment : =, +=, -=, *=....
        comparision : >,<,>=,<=,!=,==
        logical : and, or, not
        identity : is, is not
        membership : in, not in
    4- taking user input
        to take input from user, we have to use input() built in method in python
    4- conditional statements
        when execution of action is depends on condition
        ex : action : watch movie on laptop / go on bike ride
             condition : rain 
             if there is rain ---> watch movie on laptop
             otheriwise(else) ---------> go on bike ride

             but in python to undertsnd conditional statements we have to use : if, elif, else
             if (condition)-------> when there is only one collection
             elif (condition)-----> when there are multilple conditions
             else ----------------> to show default action

    6- transfer statements
